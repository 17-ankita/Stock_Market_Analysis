# Stock Market Analysis Dashboard

An end-to-end data analytics dashboard built using **Python, SQL, Streamlit, Pandas, Plotly, and Power BI concepts** to analyze small-cap stock market companies with market capitalization below ₹500 crore.

## Live Demo

https://stock-market-analysis500.streamlit.app/

## Project Overview
This project analyzes stock market companies with market capitalization below ₹500 crore to identify industry trends, regional opportunities, client potential, website quality gaps, UX performance issues, and business opportunities for Inmogic Technologies.
The dashboard focuses on converting raw company-level data into meaningful business insights using data analytics, visualization, and interactive reporting.

## Features
- Interactive Streamlit dashboard
- Dynamic sidebar filters
- Industry-wise market landscape analysis
- Market capitalization comparison
- Client potential analysis using ROCE and profit percentage
- Regional opportunity analysis
- Website quality assessment
- UX score vs performance score analysis
- Design issue identification
- Potential client targeting for Inmogic Technologies
- SQL-style business insights
- Dataset explorer

## Dashboard Modules

### 1. Market Landscape
- Company count by industry
- Total market capital by industry
- Sector distribution
- Industry-level business potential

### 2. Client Potential
- Top companies by ROCE
- Top companies by profit percentage
- High-potential client scorecard
- Financial performance comparison

### 3. Regional Opportunities
- Company count by headquarters
- Average market capital by region
- Regional concentration of potential clients
- Location-based opportunity mapping

### 4. Website Quality
- Average website design score by industry
- Website design type vs design issues
- UX score vs performance score
- Digital presence gap analysis

### 5. Inmogic Opportunities
- Potential clients by industry
- Potential clients by region
- Companies with weak website quality
- Companies with performance or design issues
- Target list for service opportunities

## Dataset Details
The dataset contains company-level stock market and digital presence information such as:

- Company name
- Industry type
- Headquarters
- Market capitalization
- ROCE
- Profit percentage
- Website design score
- Website design type
- UX score
- Performance score
- Design issue count

## Key Insights
- Manufacturing and IT sectors show strong business potential.
- High ROCE companies can be considered financially stable potential clients.
- Regional clusters help identify priority cities for business outreach.
- Companies with lower website design scores indicate digital improvement opportunities.
- UX and performance scores help identify companies that may need website optimization.
- Inmogic Technologies can use these insights for targeted client acquisition and service positioning.
